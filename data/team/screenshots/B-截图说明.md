# B 部分前台截图说明

> 负责人：B 张雅程（前台页面与用户交互）
> 截图尺寸：1440×900 或 1920×1080；截图前按 `Ctrl + F5` 强制刷新。
> 保存位置：`data/team/screenshots/`，文件名统一加 `B-` 前缀。

## 一、启动

```bat
php -S 127.0.0.1:8081 -t frontend\web
php -S 127.0.0.1:8082 -t backend\web
```

前台统一前缀：`http://127.0.0.1:8081/index.php?r=`
后台（C 的模块）：`http://127.0.0.1:8082/index.php?r=`，账号 `admin / 123456`。

## 四、截留言成功页的步骤

1. 打开 `message/index`，填写昵称（2 个字以上）和留言内容（5 个字以上）；
2. 点“提交留言”；
3. 页面跳转到“留言提交成功”后截图，确认能看到留言编号和“待审核”标签；
4. 再去后台“留言管理”通过并回复这条留言；
5. 回到前台打开 `message/mine` 刷新，截“已通过 + 管理员回复”作为联调证明。

## 五、注意

- 不要截到书签栏、其他标签页和地址栏里的无关内容；
- 字体太小可以按 `Ctrl + +` 放大到 125%，但要保证整页文字不被裁掉；
- 截图里如果留言墙为空，先让管理员通过一条演示留言再截；
- 首页较长，建议用浏览器的“捕获整页”或分两张截（主视觉一张、团队/留言一张）。
