# 团体作业提交目录（data/team）

课程要求团体作业统一放在 `/data/team/`，本目录用于汇总三名成员的交付物。
当前已放入 C（后台管理与统计）的实现文档和展示 PPT，其余文件由 A、B 补充。

## 目录结构

```
data/team/
  README.md                     本说明
  docs/
    C-后台实现文档.docx          C 的实现文档（Word，可提交）
    C-后台实现文档.md            C 的实现文档（Markdown 源文）
  ppt/
    世界杯团队项目展示.pptx      团队展示 PPT（15 页，C 整理）
  screenshots/                  运行截图（提交前补齐）
```

## 提交前检查清单

- [ ] 队名、三名成员姓名/学号已填入 PPT 封面和成员管理页面
- [ ] 前台截图：首页、球队、比赛、新闻、留言（B）
- [ ] 后台截图：登录、统计、球队、球员、新闻、留言、团队资料、成员（C）
- [ ] 数据库截图：表结构、ER 图（A）
- [ ] 需求文档、设计文档、用户手册、部署文档（按分工）
- [ ] `data/install.sql` 可在新库导入并恢复数据
- [ ] Git 提交记录截图（三人各自提交）
- [ ] 任务看板截图
- [ ] PPT 中所有虚线框替换为真实截图
- [ ] 邮件提交前确认收件地址与截止时间（以老师最新通知为准）

## 说明

- `docs/C-后台实现文档.docx` 与 `docs/C-后台实现文档.md` 内容一致，Word 版用于提交。
- PPT 中标注“截图占位”的虚线框需要替换为实际运行截图。
- 截图建议统一 1440×900 或 1920×1080，文件名用“模块-页面.png”。
