# 用户操作手册（前台）

> 课程：互联网数据库开发　项目：2026 世界杯赛事信息与球迷交流平台
> 适用对象：普通球迷用户；需要配合演示的管理员
> 编写：B 张雅程（前台页面与用户交互）　日期：2026-11-11

---

## 一、这个网站能做什么

这是一个世界杯主题的课程项目，前台可以：

- 查看比赛赛程、比分、场馆，按小组和状态筛选；
- 查看小组积分榜；
- 查看球队列表、球队详情、球员名单和球队参加的比赛；
- 阅读已发布的赛事新闻；
- 不用登录就能给球迷留言，并跟踪自己的留言是否通过审核；
- 查看课程团队（越位三剑客）的成员和分工。

> 页面里的球队、赛程、比分和新闻都是**演示数据**，不代表官方赛事信息。

## 二、打开系统

### 2.1 启动（管理员或演示者操作）

在项目根目录执行：

```bat
php -S 127.0.0.1:8081 -t frontend\web
php -S 127.0.0.1:8082 -t backend\web
```

### 2.2 访问地址

| 用途 | 地址 |
|---|---|
| 前台首页 | `http://127.0.0.1:8081/index.php?r=site/index` |
| 后台登录 | `http://127.0.0.1:8082/index.php?r=site/login` |

- 浏览器建议 Chrome / Edge。
- 如果页面样式是旧的，按 `Ctrl + F5` 强制刷新。
- 后台演示账号：`admin / 123456`（由 C 的后台模块提供）。

## 三、普通用户怎么用

### 3.1 首页

打开首页后可以看到：

1. 顶部主视觉：项目名称、主题说明、团队口号和三个主要按钮；
2. **赛事概览**：球队、比赛、已发布新闻、场馆四个数字（来自数据库，后台增删后会变化）；
3. **最新新闻**：最近 3 篇已发布新闻，点标题或“阅读全文”进入详情；
4. **近期比赛**：待开赛/进行中的比赛，没有时显示最近结束的比赛；
5. **团队与分工**：三名成员的姓名、分工、学号；
6. **球迷留言**：最近 3 条已通过审核的留言和管理员回复；
7. **快速入口**：比赛赛程、小组积分榜、球队信息、场馆信息。

顶部导航共 8 项：首页、比赛赛程、小组积分榜、球队信息、新闻资讯、球迷留言、场馆信息、团队介绍。

### 3.2 看比赛

1. 点导航“比赛赛程”进入比赛列表；
2. 在筛选栏选择“比赛小组”和“比赛状态”，点“筛选比赛”；
3. 点“重置”回到全部比赛；
4. 点比赛行末的“详情”查看比赛时间、对阵、比分、场馆和状态；
5. 点“查看小组积分榜”可以看到各组的场次、胜平负、进失球和积分排名。

### 3.3 看球队

1. 点导航“球队信息”进入列表；
2. 点球队名称或“查看详情”；
3. 详情页有球队简介、国家、小组、球员名单和比赛记录；
4. 球员名单为空时会显示“该球队暂时没有球员记录”。

### 3.4 看新闻

1. 点导航“新闻资讯”；
2. 页面上方可以按“赛事新闻 / 球队动态 / 公告”分类筛选；
3. 点标题或“阅读全文 →”进入详情；
4. 详情页显示分类、发布时间、发布人、正文，底部有同分类的“相关新闻”。

> 前台**只显示已发布**的新闻。管理员把新闻改回草稿后，前台刷新就不再显示。

### 3.5 提交留言（不用登录）

1. 点导航“球迷留言”；
2. 在左侧“我要留言”里填写：
   - **昵称**：必填，2～80 个字符；
   - **邮箱**：选填，方便管理员联系；
   - **留言主题**：选填；
   - **留言内容**：必填，5～2000 个字符；
3. 点“提交留言”；
4. 提交成功后进入“留言提交成功”页，显示留言编号、昵称、提交时间和状态“待审核”；
5. 点“查看我的留言”可以看到自己提交过的留言。

**校验提示说明**

| 情况 | 页面提示 |
|---|---|
| 昵称或内容没填 | 对应输入框下方显示“昵称不能为空”“留言内容不能为空” |
| 昵称太短 | “昵称至少 2 个字符。” |
| 内容太短 | “留言内容至少 5 个字符。” |
| 内容超长 | “留言内容不能超过 2000 个字符。” |
| 10 秒内连续提交 | “留言提交太频繁，请等待 10 秒后再试。” |

### 3.6 查看“我的留言”和审核状态

点留言板下方或成功页的“查看我的留言”：

- 本页只显示**当前浏览器**提交的留言，最多最近 20 条，不会看到别人的留言；
- 状态有三种：

| 状态 | 含义 | 前台是否公开 |
|---|---|---|
| 待审核 | 刚提交，管理员还没处理 | 否 |
| 已通过 | 管理员审核通过 | 是，会出现在留言墙 |
| 已拒绝 | 管理员审核不通过 | 否 |

- 管理员填写回复后，留言卡片下方会出现“管理员回复”和回复时间；
- 管理员审核后，**刷新本页**即可看到状态变化。

### 3.7 团队介绍

点导航“团队介绍”：

- 团队名称、口号、简介来自后台“团队资料”；
- 三名成员的姓名、分工、学号来自后台“成员管理”；
- 页面下方有三人分工说明、协作流程、技术栈和本页对应的代码目录。

## 四、管理员配合操作（后台由 C 负责）

演示“前后台闭环”时，需要管理员在后台做三件事。后台地址：`http://127.0.0.1:8082/index.php?r=`。

### 4.1 发布 / 撤回新闻

1. 登录后台，进入“内容管理 → 新闻管理”；
2. 新建新闻，填写标题、分类、摘要、正文，状态选“已发布”，保存；
3. 前台刷新“新闻资讯”，能看到新新闻；
4. 把状态改为“草稿”保存，前台刷新后该新闻消失。

### 4.2 审核 / 回复留言

1. 进入“内容管理 → 留言管理”；
2. 找到刚提交的“待审核”留言，点“查看”；
3. 填写“管理员回复”，状态选“已通过”，保存（或直接点“通过审核”）；
4. 前台“留言板”刷新，能看到这条留言和回复；
5. 前台“我的留言”刷新，状态由“待审核”变成“已通过”。

### 4.3 维护团队资料和成员

1. 进入“团队设置 → 团队资料”，修改团队名称、口号、简介、联系邮箱，保存；
2. 进入“团队设置 → 成员管理”，补填三名成员的学号和分工，保存；
3. 前台“团队介绍”和首页“团队与分工”刷新后同步变化。

> 第一次运行时如果成员列表为空，执行一次 `php yii migrate`，
> B 的数据迁移会自动补上三名成员；后台已有成员时不会重复插入。

## 五、一次完整演示流程（约 10 分钟）

1. 启动前后台，打开前台首页，介绍主视觉和 4 个数据库统计数字；
2. 依次点导航：比赛赛程 → 筛选 → 比赛详情 → 积分榜；
3. 点“球队信息”→ 球队详情（球员 + 比赛记录）；
4. 点“新闻资讯”→ 新闻详情 → 相关新闻；
5. 点“球迷留言”，提交一条留言，停在“留言提交成功”页；
6. 切到后台，在留言管理里通过并回复这条留言；
7. 回到前台，打开“我的留言”刷新，状态变为“已通过”，看到管理员回复；
8. 打开“团队介绍”，介绍三名成员和分工；
9. 后台发布一条新闻、撤回一条新闻，前台刷新证明数据来自数据库；
10. 说明 404 页（例如访问 `news/view&id=999`）也是中文提示，不会出现 PHP 报错。

## 六、常见问题

**Q1：页面打不开怎么办？**
确认两个 `php -S` 窗口没有关闭；前台是 8081，后台是 8082，端口不能重复。

**Q2：页面样式是旧的？**
按 `Ctrl + F5` 强制刷新。

**Q3：首页的新闻/留言/成员是空的？**
说明数据库里还没有对应数据。执行 `php yii migrate` 补演示数据，或让管理员在后台发布新闻、审核留言、添加成员。

**Q4：提交留言后留言墙没有出现？**
留言需要管理员审核，状态为“待审核”时不会公开。到后台“留言管理”通过后才会显示。

**Q5：同一个浏览器看不到以前提交的留言？**
“我的留言”按浏览器会话记录，清除 Cookie 或换浏览器后会丢失。演示时请在同一个浏览器里完成提交和查看。

**Q6：新闻详情打不开，显示“这篇新闻不存在”？**
新闻可能已经撤回为草稿，或者地址里的 `id` 不存在。点“返回新闻列表”重新选择。

**Q7：留言提交提示太频繁？**
两次提交至少间隔 10 秒，稍等再试。

**Q8：为什么球队详情没有“简介”字段？**
球队表只有名称、国家、小组三个信息字段，详情页的简介是用这三项拼出来的说明文字。
